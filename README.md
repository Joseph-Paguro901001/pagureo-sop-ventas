# SOP interactivo de ventas Pagureo

Guía interactiva del procedimiento de ventas presenciales, actualizada con la campaña de Black Friday. Incluye la ruta de atención, perfiles de clientes, preguntas abiertas y cerradas, y manejo de objeciones.

## Uso

Descarga el repositorio y abre `index.html` en un navegador moderno, como Chrome o Edge. El archivo funciona localmente y no requiere instalación.

Para publicarlo con GitHub Pages, configura Pages para publicar desde la rama principal y la carpeta raíz del repositorio. El archivo de entrada ya se llama `index.html`.

Los precios, anticipos y condiciones comerciales incluidos deben revisarse con el equipo de Pagureo antes de utilizarlos.

La guía incluye los precios promocionales, una simulación orientativa de cuotas y los colores y materiales del sofá. Antes de cotizar, confirma la vigencia de la campaña, la disponibilidad y las condiciones de financiación.
